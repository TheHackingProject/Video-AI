# Visual “Soul” workflow (THP Video-AI)

Short pointer for agents. **Full methodology (FR)** : `KM/Docs/research/soul-recherche-visuelle.md`.

## What it is

- **Soul file** = one living markdown per **topic** under `KM/Docs/research/`, e.g. `git-github-vulgarisation-visuelle.md`.
- Each **mini-research** appends an **Incrément** block: metaphor, on-screen idea, what to avoid.
- **Pilot outlines** copy 1–3 bullets per scene into a **“Visual / Soul cues”** section (not the whole research file).

## When to open it

- **Before** locking scene breakdown and component choices for a new pilot.
- When a video feels **text-only** — revisit Soul + add one **non-text hero** beat per clip (diagram, split, prop, terminal excerpt, etc.).

## Pair with

- **thp-solarpunk-visual** — tokens, contrast, motion budget.
- **library-matrix.md** — text roles still apply; Soul chooses **what else** is on screen besides Typewriter.

## New topic

1. Create `KM/Docs/research/<slug>-vulgarisation-visuelle.md` from the Soul doc checklist.
2. Link it from `KM/Docs/research/README.md` and from `soul-recherche-visuelle.md` index list.
